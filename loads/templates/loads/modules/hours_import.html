For modules in {{ package }} · Change year

Use this when you have each person's hours on several modules in a spreadsheet. WAM adds up each module's hours to make its totals, and works out everyone's percentage share. You'll see a preview before anything is saved.

What the spreadsheet should look like

One row per person per module. A header row is optional; with one, the columns can be in any order.
